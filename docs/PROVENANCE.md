# Provenance

The code, manifests, and fixture rows are clean-room public materials created for this repository. Fixture utterances are synthetic text and do not originate from recordings, calls, private logs, or model output.

The research framing is supported by private artifact evidence of Turkish ASR experimentation. This public reconstruction intentionally omits private audio, reference transcripts, checkpoints, run paths, compute details, private results, and employer implementation. Add a real dataset only after documenting source, license, revision, consent/terms, and retention constraints.
